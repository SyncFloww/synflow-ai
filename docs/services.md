# SyncflowAI Services Overview

This document outlines the key services within the SyncflowAI platform and their responsibilities.

## 1. User Service
- Manages user accounts and authentication
- Handles user profiles and settings

## 2. Brand Service
- Stores brand information and configurations
- Manages linked accounts for each brand

## 3. Social Account Service
- Connects to external platforms (Instagram, Twitter, LinkedIn, TikTok, etc.)
- Handles authentication and permissions with each platform

## 4. AI Agent Service
- Monitors activities across connected accounts
- Generates context-aware actions or responses
- Maintains state and workflow history for agents

## 5. Automation Engine
- Executes scheduled tasks and workflows
- Handles triggers from AI agents
- Interacts with APIs of connected platforms

## 6. Response / Action Layer
- Sends automated messages, posts, or other actions
- Logs all activities for auditing and tracking
